# Security

This repository holds public configuration, documentation and skills for the OneHaus remote MCP server. It does not contain the OneHaus application or any household data.

Report a vulnerability in this repository, or a problem with the OneHaus service, to support@onehaus.app. Please do not open a public issue for a security report.
